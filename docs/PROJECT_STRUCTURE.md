# WattWise-ML Project Structure

## Project Overview
WattWise-ML is an energy analytics project designed to analyze energy consumption data and provide useful insights through data analysis and visualization.

## Main Project Files

- `app.py` – Main application file for the energy analytics dashboard.
- `energy_analytics_dashboard_notebook.ipynb` – Jupyter Notebook containing data analysis and project implementation.
- `README.md` – Project introduction and setup instructions.
- `docs/` – Contains project documentation.

## Documentation
This folder contains information about the project structure, files, and their purposes.
